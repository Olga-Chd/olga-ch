# Портфолио Ольги Чудиновой — GitHub Pages

Это самостоятельная версия сайта на Vanilla HTML, CSS и JavaScript.

## Публикация

Загрузите **содержимое этой папки** в корень GitHub repository:

- `index.html` должен лежать в корне repository;
- рядом с ним должны лежать `styles.css`, `script.js`, `portrait.png` и `favicon.svg`;
- в настройках repository откройте **Settings → Pages**;
- в разделе **Build and deployment** выберите `Deploy from a branch`, нужную ветку и папку `/ (root)`;
- сохраните настройки и дождитесь публикации.

Все пути к локальным файлам относительные, поэтому сайт будет работать и в GitHub Pages project site с URL вида `/repository-name/`.
